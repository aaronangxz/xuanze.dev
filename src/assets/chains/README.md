# Hotel chain logos

One SVG per chain, named by the chain in lower case with spaces removed: `marriott.svg`, `hilton.svg`, `ihg.svg`, `hyatt.svg`,
`accor.svg`, `wyndham.svg`, `fourseasons.svg`, `panpacific.svg`.
The hotel collection shows the logo alone (the chain's name is kept for screen readers), painted in the page's ink colour,
so a single-colour file works best. A chain without a file shows its name instead (as Independent does).

`marriott.svg` and `hilton.svg` come from Simple Icons; `hyatt.svg`, `ihg.svg`, `accor.svg` and `wyndham.svg` from Wikimedia
Commons; `fourseasons.svg` from English Wikipedia; `panpacific.svg` from worldvectorlogo. Their viewBoxes are cropped to the
artwork. Tune a logo's size in `SIZE` in `src/components/ChainLogo.astro`. The marks are the brands' trademarks.
