What I added on top of stock subagents

  • Read before write. Every builder agent starts by reading the project's CLAUDE.md and the neighbouring handlers, queries or components, and copies their patterns.
  • Fixed handoff formats. Each agent ends with a set list (new RPCs, query names, nullable fields, migrations still to run), so the hub passes exact facts instead of retelling them.
  • Briefs carry the rules. Subagents don't inherit loaded skills, so the brief includes the 3–5 rules that bind that agent.
  • Stack-specific guardrails. Never edit generated files, run codegen before handlers, auth check on every handler, batch queries instead of N+1.
