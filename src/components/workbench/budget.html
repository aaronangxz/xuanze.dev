Where the savings come from

descriptions route, bodies executeRouting reads only the always-loaded descriptions. A body loads when its phase actually starts.
once per sessionA loaded skill is applied from context afterwards. It's re-read only if compaction dropped it or the file changed.
most specific winsA task that matches one skill goes straight to it, skipping the orchestrator's ~2.3k-token body.
reasoned skipsScoping, design docs, UX flows and code review each have a skip condition. A skipped phase costs one ledger line.
references just in time16.5k tokens of deep material load only during the sub-task that needs them.
scripts over re-derivationlint-spec.sh and flake-rate.sh run and return a result. The checks aren't re-reasoned in context each time.
distilled briefsA subagent gets the 3–5 rules that bind it, never a pasted skill body. Its noisy reads stay in its own window.
outcome-first reportsReports lead with the result and a scope note; the journey stays in the transcript. The ledger stops the next session re-deriving decisions.
